# GlowUp

## Datos del proyecto

Autora: Marina Arrieta

## Descripción

GlowUp es una Aplicación web de tipo ecommerce orientado a la venta de productos de maquillaje y belleza.
La aplicación cuenta con cuatro categorías de productos: rostro, ojos, labios y brochas y accesorios.
El objetivo del proyecto es desarrollar la estructura inicial de una tienda online utilizando HTML, incorporando diferentes páginas para navegar entre las categorías, además de páginas de inicio de sesión y registro de usuarios.
